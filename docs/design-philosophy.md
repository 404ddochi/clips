# CLIPS Design Philosophy

CLIPS는 게임을 소개하는 사이트가 아니다.  
CLIPS는 플레이어가 원하는 게임 정보를 가장 빠르게 찾는 사이트다.

## Slogan

**Find Faster. Read Less. Play More.**

더 빨리 찾고,  
덜 읽고,  
더 많이 플레이한다.

관련 문서: [CDL](13-clips-design-language.md) · [테마](14-theme-system.md) · [정보 페이지](15-information-pages.md)

## Core Principles

1. 정보가 디자인보다 우선한다.
2. 화려함보다 탐색 속도를 우선한다.
3. 애니메이션보다 가독성을 우선한다.
4. 불필요한 여백보다 정보 밀도를 우선한다.
5. 모든 페이지를 동일한 카드 레이아웃으로 만들지 않는다.
6. 페이지별 핵심 사용자 행동을 먼저 정의한다.
7. 가장 중요한 행동을 최소한의 클릭으로 수행할 수 있어야 한다.
8. 데스크톱과 모바일 모두 빠른 정보 확인이 가능해야 한다.
9. 장식 요소는 정보를 방해하지 않는 범위에서만 사용한다.
10. CLIPS 디자인 시스템과 다크/라이트 테마의 일관성을 유지한다.

## Page Purpose

| 페이지 | 핵심 목적 |
|--------|-----------|
| 뉴스 | 읽는다. |
| 공지사항 | 중요한 내용을 확인한다. |
| 이벤트 | 진행 여부와 보상을 확인한다. |
| 패치노트 | 변경점을 찾는다. |
| 쿠폰 | 코드를 찾고 복사한다. |
| 클래스 | 특징과 성능을 비교한다. |
| 보스 | 위치, 리젠 시간, 드랍 아이템을 찾는다. |
| 아이템 | 검색하고 획득처를 찾는다. |

## Page Design Process

새로운 페이지를 만들 때는 아래 순서를 따른다.

1. 페이지의 핵심 목적을 정의한다.
2. 사용자의 주요 행동 흐름을 정의한다.
3. 대표 컴포넌트를 정의한다.
4. 정보 우선순위를 결정한다.
5. 데스크톱 레이아웃을 설계한다.
6. 모바일 레이아웃을 별도로 최적화한다.
7. 키보드 접근성 및 상태 표현을 검토한다.
8. 테스트 후 다음 페이지로 넘어간다.

### 예시: 쿠폰

- **목적:** 쿠폰 코드를 빠르게 찾고 복사한다.
- **사용자 행동:** 필터 → 확인 → 복사
- **대표 컴포넌트:** Coupon Row
- **정보 우선순위:** 상태 → 코드 → 보상 → 기간 → 출처 → 복사
- **레이아웃:** 고밀도 가로 리스트 (카드 그리드 지양)
